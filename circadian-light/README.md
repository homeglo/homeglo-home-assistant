# Circadian Light by HomeGlo

Circadian Light honors your circadian rhythm by adapting your smart lights' color and brightness to your daily pattern.

This app runs the HomeGlo "Brain" inside Home Assistant. The HomeGlo phone App controls it.

- Supports aarch64 and amd64.
- The app images are private. Before you install, add a registry with the credentials HomeGlo gave you. See the Documentation tab for the steps.
- Already have a working HomeGlo home? Do not install a second copy. Contact hello@home-glo.com.
