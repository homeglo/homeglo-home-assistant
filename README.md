# HomeGlo for Home Assistant

Stable metadata feed: `https://github.com/homeglo/homeglo-home-assistant.git#stable`. Keep this reference for future releases.

Documentation: [HomeGlo add-on guide](circadian-light/DOCS.md).

Engine images are private; authorized download access is required. Existing homes require an attended first enrollment that preserves their setup and identity. Do not start a second Brain beside the working one. Once enrolled, use the normal Home Assistant Update and Backup/Restore controls.

This branch contains only add-on metadata and release notes. Engine source and images are not public. Other architectures will be listed only after their releases are accepted and published.
